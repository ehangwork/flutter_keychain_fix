# flutter_keychain_fix_example

Demonstrates the `flutter_keychain_fix` plugin: reading, writing, removing and clearing
values, plus iOS access group and label configuration.

## Running

```bash
flutter run
```

The app stores a `firstStart` timestamp on first launch and shows it on subsequent
launches, so you can see a round trip through the platform's secure store.

## Tests

```bash
flutter test
```
